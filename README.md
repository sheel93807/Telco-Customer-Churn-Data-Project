# 📞 Telecommunications Customer Churn Analysis

## 📋 Project Overview

This project analyzes customer churn patterns within a telecommunications company to identify factors associated with customer retention and customer loss.

Using customer demographics, account information, services, contract details, and billing data, the analysis explores the characteristics most commonly associated with churn.

The project uses Python, SQL, and Power BI to transform data into actionable business insights.

## 🎯 Project Objective

Identify customer segments with elevated churn risk and uncover key factors associated with customer retention.

## 📁 Dataset Overview

* 📄 7,043 Customer Records
* 📉 1,869 Churned Customers
* 📈 26.54% Overall Churn Rate



## 🔄 Project Workflow

### 🧹 Data Preparation

* Cleaned customer demographic and account data
* Validated missing values
* Converted categorical variables for analysis
* Prepared data for reporting and visualization

### 🗃️ Data Analysis

* Evaluated churn trends by contract type
* Compared churn by internet service
* Reviewed payment method behavior
* Analyzed customer tenure and retention factors

### 📊 Dashboard Development

Created an interactive Power BI dashboard featuring:

* Customer Churn KPIs
* Churn by Contract Type
* Churn by Internet Service
* Churn by Payment Method
* Customer Tenure Analysis

## 🔑 Key Findings

* 📉 Overall churn rate was 26.54%.
* 📄 Month-to-month contracts experienced the highest churn rate at 42.7%.
* 🌐 Fiber optic customers showed a churn rate of 41.9%.
* 💳 Electronic check customers had the highest churn rate at 45.3%.
* ⏳ Customer churn decreased significantly as tenure increased.

## 🧾 Project Conclusion

Contract length and customer tenure were among the strongest indicators of retention.

Customers with month-to-month contracts and shorter tenure exhibited substantially higher churn rates than customers with long-term agreements.

The analysis demonstrates how customer behavior data can be used to identify at-risk customer segments and support retention strategies.
